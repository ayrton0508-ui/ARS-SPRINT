ARS SPRINT V26.4 — V25
Flujo simplificado de cámara en vivo.

Uso:
1. Selecciona deportista y distancia (5/10/20 m).
2. Elige cámara trasera o frontal.
3. Pulsa COMENZAR PRUEBA.
4. Espera a que aparezca ATLETA DETECTADO.
5. La app arma la medición automáticamente; corre desde INICIO hasta FINAL.

Importante: el acceso a cámara requiere HTTPS (por ejemplo GitHub Pages) y permiso de cámara. Abrir index.html directamente como archivo local puede impedir getUserMedia en iPad/Safari.
La distancia física debe estar previamente medida/calibrada; la superposición visual es una guía y no sustituye una medición física.
