METODOLOGÍA

Protocolo de medición

ARS SPRINT 10.0 SMART VALIDATION 8.2

1. Estandarización

Conservar distancia, protocolo de salida, superficie, cámara y condiciones entre sesiones. Registrar estos campos con cada evaluación.

2. Vídeo

Preferir cámara lateral, plano estable, línea de salida y llegada visibles y la mayor frecuencia de cuadros disponible. El FPS declarado determina la resolución temporal nominal.

3. Marcaje

Inicio: primer apoyo definido por el protocolo. Final: instante de cruce de la línea de llegada por el segmento corporal definido. Mantener el mismo criterio entre sesiones.

4. Interpretación

No confundir más decimales con mayor exactitud. El software informa resolución temporal, calidad y consistencia; no inventa una precisión que el vídeo no permite.

Base científica incorporada

  • Los tiempos de sprint cortos presentan errores relevantes según el método y la distancia.
  • La estandarización del inicio es crítica para comparar 5–10 m.
  • Las pruebas de 5–20 m son útiles para monitorizar aceleración; 0–10 y 0–20 m tienen mejor utilidad para detectar cambios que algunos splits intermedios, por lo que el software informa el método y no declara exactitud científica.
  • Para máxima precisión práctica, los sistemas de fotocélulas siguen siendo un criterio de referencia; el vídeo es una alternativa de bajo coste que debe validarse.
