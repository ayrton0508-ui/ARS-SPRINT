# ARS SPRINT
Aplicación PWA de medición de sprint por cámara. Alcance oficial: 5, 10 y 20 m.

## Flujo
Una cámara lateral → IA corporal → calibración 0/5/10/20 → armado automático → salida automática → splits → velocidad/Vmax → vídeo → historial.

## Requisitos
Servir por HTTPS o localhost. La IA usa MediaPipe Tasks Vision y un modelo de pose público; requiere conexión para la primera carga del motor/modelo.

## Alcance
No incluye 5-0-5, 5-10-5, 30 m ni 40 m.
